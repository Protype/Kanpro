# Kanpro 功能規格文件

本文件從使用者角度描述 Kanpro 應具備的所有功能，每個功能區塊後標註對應的 Kanboard API。

---

## 1. 登入與身份驗證

### 功能描述

使用者開啟 Kanpro 時，首先看到登入頁面。輸入 Kanboard 伺服器網址、帳號密碼後登入。系統驗證成功後，儲存認證資訊供後續 API 呼叫使用。

### 使用情境

1. **首次使用**：輸入伺服器網址、帳號、密碼
2. **記住我**：勾選後下次自動登入
3. **登出**：清除本地認證資訊

### 介面元素

- 伺服器網址輸入框
- 帳號輸入框
- 密碼輸入框
- 「記住我」勾選框
- 登入按鈕
- 錯誤訊息顯示區

### 對應 API

| 功能 | API 方法 | 說明 |
|------|----------|------|
| 驗證帳號 | `getMe` | 驗證認證資訊並取得當前使用者資料 |

### 伺服器網址配置機制

伺服器網址（API URL）採用多層級配置，方便部署後統一設定：

#### 配置優先級

1. **config.json**（最高）：部署時預設的網址（`public/config.json`），有設定時鎖定不可更改
2. **localStorage**：使用者手動輸入的網址（僅在 config.json 無值時使用）
3. **空值**：需要使用者輸入

#### 介面行為

| 狀態 | 顯示方式 | 可用操作 |
|------|----------|----------|
| config.json 有值 | 虛線底連結（鎖定） | 點擊連結開新分頁 |
| config.json 無值 | 輸入框 | 輸入網址（登入成功後快取至 localStorage） |

#### URL 正規化

- 使用者輸入時不需包含 `jsonrpc.php`
- 系統在 API 呼叫時自動補上 `/jsonrpc.php`
- 儲存與顯示皆為不含 `jsonrpc.php` 的網址

#### 部署設定

1. 複製 `public/config.example.json` 為 `public/config.json`
2. 修改 `apiUrl` 為目標 Kanboard 伺服器網址
3. `config.json` 已加入 `.gitignore`，不會進入版本控制

## 2. 儀表板（Dashboard）

### 功能描述

登入後的首頁，顯示使用者的工作概覽：待辦任務、專案列表、最近活動等。讓使用者快速掌握工作狀態。

### 使用情境

1. **查看我的任務**：顯示指派給我的所有任務，按專案或到期日分組
2. **快速存取專案**：點擊專案名稱直接進入看板
3. **查看逾期任務**：醒目顯示已逾期的任務
4. **查看通知**：未讀通知提示

### 介面元素

- 專案列表卡片
- 我的任務清單
- 逾期任務警示
- 通知圖示與數量
- 快速新增任務按鈕

### 對應 API

| 功能 | API 方法 | 說明 |
|------|----------|------|
| 取得專案列表 | `getAllProjects` | 取得使用者可存取的所有專案 |
| 取得我的任務 | `searchTasks` | 使用 `assignee:me status:open` 搜尋 |
| 取得逾期任務 | `getOverdueTasks` | 取得所有逾期任務 |
| 取得使用者資訊 | `getMe` | 取得當前登入使用者資訊 |

## 3. 專案列表

### 功能描述

顯示使用者可存取的所有專案，支援搜尋與篩選。使用者可從這裡進入特定專案，或建立新專案。

### 使用情境

1. **瀏覽專案**：以卡片或列表形式顯示所有專案
2. **搜尋專案**：輸入關鍵字快速找到專案
3. **建立專案**：點擊「新增專案」開啟建立表單
4. **專案狀態**：區分啟用中與已停用的專案

### 介面元素

- 專案卡片/列表
- 搜尋框
- 新增專案按鈕
- 專案狀態標籤（啟用/停用）
- 專案成員頭像

### 對應 API

| 功能 | API 方法 | 說明 |
|------|----------|------|
| 取得專案列表 | `getAllProjects` | 取得所有專案 |
| 取得單一專案 | `getProjectById` | 取得專案詳細資訊 |
| 建立專案 | `createProject` | 建立新專案 |

## 4. 專案設定

### 功能描述

管理專案的基本資訊、成員權限、欄位、泳道、類別等設定。只有專案管理員可存取。

### 使用情境

1. **編輯專案資訊**：修改名稱、描述、日期
2. **管理成員**：新增/移除成員、變更角色
3. **設定欄位**：新增/編輯/刪除/排序欄位
4. **設定泳道**：新增/編輯/刪除/排序泳道
5. **管理類別**：建立任務分類
6. **複製專案**：複製現有專案的設定

### 4.1 基本資訊

- 專案名稱
- 專案描述
- 專案識別碼
- 開始/結束日期
- 專案類型（團隊/個人）

### 4.2 成員管理

- 成員列表（含角色）
- 新增成員（選擇使用者/群組）
- 移除成員
- 變更成員角色

### 4.3 欄位管理

- 欄位列表（可拖曳排序）
- 新增欄位（名稱、WIP 限制、描述）
- 編輯欄位
- 刪除欄位

### 4.4 泳道管理

- 泳道列表（可拖曳排序）
- 新增泳道
- 編輯泳道
- 啟用/停用泳道
- 刪除泳道

### 4.5 類別管理

- 類別列表
- 新增類別

- 刪除類別

## 5. 看板檢視

### 功能描述

專案的主要工作介面。以欄位為直向、泳道為橫向，顯示所有任務卡片。使用者可拖放任務在欄位與泳道間移動。

### 使用情境

1. **查看任務狀態**：一眼看出各階段的任務分佈
2. **移動任務**：拖放任務至其他欄位表示進度變更
3. **快速新增任務**：點擊欄位上的 + 按鈕
4. **查看任務詳情**：點擊任務卡片開啟詳情
5. **折疊泳道**：點擊泳道標題折疊/展開
6. **WIP 限制警示**：欄位超過限制時變紅

### 介面元素

- 欄位標題（含任務數量、WIP 限制）
- 泳道標題（可折疊）
- 任務卡片（標題、指派人、標籤、到期日）
- 新增任務按鈕
- 篩選器
- 檢視模式切換

### 卡片顯示資訊

- 任務標題
- 任務編號
- 指派人頭像
- 顏色標籤
- 標籤
- 到期日（逾期顯示紅色）
- 子任務進度
- 評論/附件數量

### 對應 API

| 功能 | API 方法 | 說明 |
|------|----------|------|
| 取得看板資料 | `getBoard` | 取得完整看板狀態（泳道、欄位、任務） |
| 移動任務 | `moveTaskPosition` | 移動任務至其他欄位/泳道/位置 |

## 10. 搜尋與篩選

### 功能描述

全域搜尋功能，支援強大的搜尋語法，可快速找到任務。

### 使用情境

1. **快速搜尋**：按 Cmd/Ctrl + K 開啟搜尋
2. **進階篩選**：使用搜尋語法
3. **儲存篩選器**：常用搜尋條件存為篩選器

### 搜尋語法

```
# 基本搜尋
關鍵字                    # 搜尋標題
#123                     # 任務編號

# 狀態篩選
status:open              # 開啟中的任務
status:closed            # 已關閉的任務

# 人員篩選
assignee:me              # 指派給我
assignee:nobody          # 未指派
assignee:"張三"          # 指派給特定人
creator:me               # 我建立的

# 日期篩選
due:today                # 今天到期
due:tomorrow             # 明天到期
due:2024-01-15           # 特定日期
due:<=2024-01-15         # 在此日期前到期
overdue:yes              # 已逾期

# 屬性篩選
color:blue               # 藍色任務
category:"Bug"           # 特定類別
tag:"urgent"             # 特定標籤
swimlane:"Sprint 1"      # 特定泳道
column:"In Progress"     # 特定欄位

# 組合搜尋
assignee:me due:today status:open
```

### 對應 API

| 功能 | API 方法 | 說明 |
|------|----------|------|
| 搜尋任務 | `searchTasks` | 使用搜尋語法搜尋 |

## 14. 專案分析（進階功能）

### 功能描述

專案數據分析，透過圖表呈現專案狀態與趨勢。

### 報表類型

1. **任務分佈圓餅圖**：各欄位的任務數量
2. **使用者工作量**：各成員負責的任務數
3. **累積流程圖**：任務在各欄位隨時間的變化
4. **燃盡圖**：剩餘工作量趨勢
5. **平均欄位停留時間**：任務在各階段的平均時間
6. **Lead/Cycle Time**：任務從建立到完成的時間趨勢

## 附錄：API 通訊規格

### JSON-RPC 2.0 格式

**請求格式**
```json
{
  "jsonrpc": "2.0",
  "method": "getTask",
  "id": 1,
  "params": {
    "task_id": 123
  }
}
```

**回應格式**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": { ... }
}
```

### 認證方式

使用 HTTP Basic Authentication：
- 使用者名稱：`jsonrpc` 或使用者帳號
- 密碼：API Token 或使用者密碼

### API 端點

```
POST {kanboard_url}/jsonrpc.php
```
