# Kanpro i18n 國際化架構設計

## 概述

為 Kanpro 建立國際化 (i18n) 架構，初期支援英文 (`en_US`) 與繁體中文 (`zh_TW`)。英文術語完全對照 Kanboard 官方用詞。

## 技術選型

- **函式庫**: vue-i18n v9 (Vue 3 官方 i18n 方案)
- **語言代碼**: 使用 Kanboard 格式 (`en_US`, `zh_TW`)

## 檔案結構

```
src/
  i18n/
    index.ts              # i18n 實例與設定
    locales/
      en_US.json          # 英文翻譯（對照 Kanboard 官方術語）
      zh_TW.json          # 繁體中文翻譯
```

## 語言偵測優先序

```
1. localStorage('kanpro-locale')     ← Kanpro 獨立設定
   ↓ 若無
2. user.language                      ← Kanboard 使用者設定 (API)
   ↓ 若無或不支援
3. navigator.language                 ← 瀏覽器語言
   ↓ 若不支援
4. 'en_US'                           ← 預設
```

## 實作細節

### i18n 初始化 (`src/i18n/index.ts`)

```typescript
import { createI18n } from 'vue-i18n'
import en_US from './locales/en_US.json'
import zh_TW from './locales/zh_TW.json'

export const SUPPORTED_LOCALES = ['en_US', 'zh_TW'] as const
export type SupportedLocale = typeof SUPPORTED_LOCALES[number]

export function detectLocale(userLanguage?: string | null): SupportedLocale {
  // 1. Kanpro localStorage
  const stored = localStorage.getItem('kanpro-locale')
  if (stored && SUPPORTED_LOCALES.includes(stored as SupportedLocale)) {
    return stored as SupportedLocale
  }

  // 2. Kanboard user.language
  if (userLanguage && SUPPORTED_LOCALES.includes(userLanguage as SupportedLocale)) {
    return userLanguage as SupportedLocale
  }

  // 3. Browser language (navigator.language: "zh-TW" → "zh_TW")
  const browserLang = navigator.language.replace('-', '_')
  if (SUPPORTED_LOCALES.includes(browserLang as SupportedLocale)) {
    return browserLang as SupportedLocale
  }

  // 4. Default
  return 'en_US'
}

export function setLocale(locale: SupportedLocale): void {
  i18n.global.locale.value = locale
  localStorage.setItem('kanpro-locale', locale)
  document.documentElement.lang = locale.replace('_', '-')
}

export function clearLocaleOverride(): void {
  localStorage.removeItem('kanpro-locale')
}

export const i18n = createI18n({
  legacy: false,
  locale: 'en_US',
  fallbackLocale: 'en_US',
  messages: {
    en_US,
    zh_TW
  }
})

export default i18n
```

### main.ts 整合

```typescript
import { createApp } from 'vue'
import App from './App.vue'
import i18n from './i18n'

const app = createApp(App)
app.use(i18n)
app.mount('#app')
```

### 元件使用方式

```vue
<template>
  <button>{{ $t('common.save') }}</button>
  <span>{{ $t('task.dueDate') }}</span>
</template>

<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t } = useI18n()

</script>
```

### 登入後初始化

```typescript
// auth store 登入成功後
const locale = detectLocale(user.language)
setLocale(locale)
```

### 使用者設定頁語言選項

| 選項 | 行為 |
|------|------|
| 跟隨 Kanboard 設定 | `clearLocaleOverride()` → 下次載入使用 `user.language` |
| English (en_US) | `setLocale('en_US')` |
| 繁體中文 (zh_TW) | `setLocale('zh_TW')` |

### 日期格式化

使用 vue-i18n 的日期格式化或保留現有 `toLocaleDateString()`，動態傳入 locale：

```typescript
const { locale } = useI18n()
const formattedDate = date.toLocaleDateString(locale.value.replace('_', '-'))
```

## 測試計畫

### 單元測試

1. `detectLocale()` 函數測試
   - localStorage 有值時優先使用
   - 無 localStorage 時使用 user.language
   - 無 user.language 時使用瀏覽器語言
   - 皆無時使用預設值

2. `setLocale()` 函數測試
   - 正確設定 i18n locale
   - 正確儲存至 localStorage
   - 正確設定 document.documentElement.lang

3. `clearLocaleOverride()` 函數測試
   - 正確清除 localStorage

### 整合測試

1. 登入流程語言初始化
2. 使用者設定頁語言切換
3. 語言切換後 UI 即時更新

### E2E 測試

1. 完整切換語言流程
2. 驗證所有主要頁面文字正確顯示
