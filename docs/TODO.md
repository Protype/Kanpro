# Kanpro 開發待辦清單

依據 Kanboard API 欄位和功能需求整理的開發任務。

**格式說明**：`- [ ] [實作] [ ] [測試] 項目名稱`
- 第一個 checkbox：實作完成
- 第二個 checkbox：實機測試完成（agent-browser 或 chrome-devtools 驗證）

---

## 一、專案管理功能

### 1.1 專案快速建立（燈箱）

快速建立模式：只顯示最重要的欄位，讓使用者能快速建立專案。

**Kanboard createProject API 支援欄位：**
- `name` (必填) - 專案名稱
- `description` - 專案描述
- `owner_id` - 擁有者 ID
- `identifier` - 專案識別碼
- `start_date` - 開始日期
- `end_date` - 結束日期
- `is_private` - 是否為私人專案

**快速建立欄位（燈箱 - 精簡版）：**

- [ ] [實作] [ ] [測試] 專案名稱（必填）
- [ ] [實作] [ ] [測試] 專案描述（選填，可折疊）
- [ ] [實作] [ ] [測試] 專案識別碼（選填，自動產生建議值）
- [ ] [實作] [ ] [測試] 私人專案切換開關
- [ ] [實作] [ ] [測試] 建立後自動導向專案看板

### 1.2 專案完整建立頁

完整建立模式：提供所有可設定欄位的獨立頁面。

- [ ] [實作] [ ] [測試] 建立獨立的 `/projects/new` 路由頁面
- [ ] [實作] [ ] [測試] 專案名稱（必填）
- [ ] [實作] [ ] [測試] 專案描述（Markdown 編輯器）
- [ ] [實作] [ ] [測試] 專案識別碼（含驗證規則顯示）
- [ ] [實作] [ ] [測試] 擁有者選擇（下拉選單，預設為當前使用者）
- [ ] [實作] [ ] [測試] 開始日期（日期選擇器）
- [ ] [實作] [ ] [測試] 結束日期（日期選擇器）
- [ ] [實作] [ ] [測試] 私人專案設定
- [ ] [實作] [ ] [測試] 表單驗證與錯誤訊息
- [ ] [實作] [ ] [測試] 建立成功後跳轉選項（看板/設定頁）

## 二、任務管理功能

### 2.1 任務快速建立（Spotlight / CommandBar）

透過 Cmd+K 快捷鍵開啟的快速建立介面。

**Kanboard createTask API 支援欄位：**
- `project_id` (必填) - 專案 ID
- `title` (必填) - 任務標題
- `description` - 任務描述
- `color_id` - 顏色 ID
- `column_id` - 欄位 ID
- `swimlane_id` - 泳道 ID
- `owner_id` - 指派人 ID
- `creator_id` - 建立者 ID
- `category_id` - 類別 ID
- `date_due` - 到期日（Unix timestamp 或 ISO 格式）
- `date_started` - 開始日期
- `score` - Story Points
- `priority` - 優先級
- `time_estimated` - 預估時間（小時）
- `time_spent` - 已花費時間（小時）
- `reference` - 外部參考
- `tags` - 標籤陣列

**快速建立符號語法：**

- [ ] [實作] [ ] [測試] `^` 專案選擇（自動帶入當前專案）
- [ ] [實作] [ ] [測試] `@` 指派人選擇（從專案成員列表）
- [ ] [實作] [ ] [測試] `#` 標籤選擇/新增
- [ ] [實作] [ ] [測試] `:` 欄位選擇
- [ ] [實作] [ ] [測試] `!` 優先級設定（1-4 或 P1-P4）
- [ ] [實作] [ ] [測試] `>` 到期日設定（支援自然語言：today, tomorrow, next week）
- [ ] [實作] [ ] [測試] `~` 泳道選擇
- [ ] [實作] [ ] [測試] `$` Story Points（數字）
- [ ] [實作] [ ] [測試] `%` 類別選擇

**功能實作：**

- [ ] [實作] [ ] [測試] Token 化輸入顯示
- [ ] [實作] [ ] [測試] 符號觸發下拉選單
- [ ] [實作] [ ] [測試] 下拉選單鍵盤導航（上下鍵、Tab、Enter）
- [ ] [實作] [ ] [測試] 自動完成搜尋過濾
- [ ] [實作] [ ] [測試] 新增標籤功能（輸入不存在的標籤時）
- [ ] [實作] [ ] [測試] 建立成功後顯示通知
- [ ] [實作] [ ] [測試] 建立成功後可選擇跳轉至任務詳情
